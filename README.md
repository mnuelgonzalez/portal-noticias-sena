# Portal de Noticias - CDTI SENA Regional Valle

Portal de noticias del Centro de Automatización Industrial del SENA.

## Tecnologías
- Python 3.14
- Django 5.2 LTS
- Bootstrap 5
- SQLite

## Características
- Panel administrativo con filtros, búsquedas y jerarquía de fechas
- Portal público responsivo
- Gestión de noticias con imágenes
